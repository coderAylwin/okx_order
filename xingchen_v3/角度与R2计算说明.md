# 布林带中轨角度 & R² 计算说明

> 适用组件：`trend_vidya_v2/trend_volumatic_dynamic_average_strategy.py` 内的 `BollingerMidlineAngleCalculator`

## 1. 数据来源

- **主周期**：默认 30m K 线（可配置）
- **中轨**：对主周期收盘价做 `bb_period`（默认 20）EMA，得到中轨序列
- **窗口**：取最近 `bb_angle_window_size`（默认 20）个中轨值参与计算

## 2. 角度计算流程

1. **标准化**：以窗口第一项为基准，换算成百分比变化：
   \[
   relative\_changes[i] = \frac{midline[i]-midline[0]}{midline[0]} \times 100\%
   \]
2. **线性回归**：以时间索引 `0…n-1` 作为 x，`relative_changes` 作为 y，最小二乘拟合直线
3. **斜率 (slope)**：拟合得到的斜率，单位 `%/bar`
4. **角度**：将斜率转成十进制涨幅（除以 100），再做反正切得到角度：
   \[
   angle = \arctan\left(\frac{slope}{100}\right) \text{ (弧度)} \Rightarrow \text{转换为度}
   \]

### 角度含义与常见区间

| 每根中轨涨跌 | slope（%/bar） | 角度（°） | 说明 |
|--------------|----------------|-----------|------|
| 0.03%        | 0.03           | ≈0.017°   | 弱趋势/震荡边缘 |
| 0.08%        | 0.08           | ≈0.046°   | 中等趋势（敏感配置常用阈值） |
| 0.15%        | 0.15           | ≈0.086°   | 较强趋势 |
| 0.30%        | 0.30           | ≈0.172°   | 强势单边 |
| 0.50%        | 0.50           | ≈0.286°   | 罕见极强趋势，通常伴随爆量行情 |

> 市场大部分时间中轨每根涨跌 <0.2%，因此角度通常落在 ±0.02°~±0.15°。只有持续爆发的行情才能超过 0.3°。

### 阈值配置指引

- 0.03°~0.05°：极敏感，易捕捉细微趋势，也容易被噪音触发
- 0.06°~0.12°：平衡信噪比（回测中常见角度 ≈0.05°）
- ≥0.2°：只确认非常强的趋势
- ≥0.3°：用于过滤掉所有非爆发行情

## 3. R²（决定系数）计算流程

在线性回归后，计算拟合优度：
\[
R^2 = 1 - \frac{SS_{res}}{SS_{tot}}, \qquad
SS_{res} = \sum (y\_i - \hat{y}\_i)^2, \quad
SS_{tot} = \sum (y\_i - \bar{y})^2
\]

- R² ∈ [0, 1]，越接近 1 表示越接近完美直线
- 若 `SS_tot = 0`（全部相等），则 R² 设为 0，避免除零

### R² 含义与常见区间

| R² 值 | 说明 | 推荐处理 |
|-------|------|----------|
| ≥0.85 | 极高拟合度，价格几乎沿直线运行 | 可视为强趋势 |
| 0.65~0.85 | 中高拟合度，趋势可靠 | 默认阈值 0.6 可捕捉到 |
| 0.45~0.65 | 中度拟合，趋势夹杂波动 | 放宽阈值后可用 |
| 0.25~0.45 | 低拟合度，容易被噪音干扰 | 视为震荡 |
| <0.25 | 无明显线性关系 | 绝大多数情况下应忽略 |

### 阈值配置指引

- **0.6（默认）**：信号质量与触发频率平衡
- **0.75~0.85**：追求更稳定走势，牺牲部分机会
- **0.45~0.55**：允许波动较大的趋势，增加信号数量
- **<0.3**：几乎失去过滤效果，不推荐

## 4. 联合判定逻辑

- 满足 `abs(angle) > angle_threshold` 且 `R² ≥ r_squared_threshold` 才算有效趋势
- 任一条件不满足 → 判定为震荡（`current_trend = '震荡'`），不会触发角度开仓信号
- R² 相当于“趋势质量控制”，即使角度大但 R² 低，依旧拒绝开仓

## 5. 调参建议

1. **先观察回测日志**中的角度分布，确保阈值落在真实范围内
2. **结合品种特点**调节：
   - 低波动标的：角度与 R² 可设更低，避免完全无信号
   - 高波动标的：适当提高阈值，过滤噪音
3. **联动调整**：
   - 降低角度阈值 ⇒ 同时需要稍微提高 R² 阈值，以免引入噪音
   - 降低 R² 阈值 ⇒ 角度阈值应提高，保证趋势强度

## 6. 快速检查模板

| 参数组合 | 适用场景 | 备注 |
|---------|----------|------|
| angle ≥ 0.05°, R² ≥ 0.6 | 默认均衡配置 | 适用于 BTC/ETH 等主流币 |
| angle ≥ 0.03°, R² ≥ 0.7 | 捕捉微趋势但要求线性 | 噪音较低的品种或行情 |
| angle ≥ 0.12°, R² ≥ 0.5 | 允许不完美拟合但要求更强斜率 | 高频震荡但趋势拉升快 |
| angle ≥ 0.2°, R² ≥ 0.7 | 只做极强趋势 | 适合回撤控制严格的模式 |

> 建议在 `strategy_configs.py` 或回测配置中同步注释当前阈值选择的理由，方便复盘。
